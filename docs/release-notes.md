9 个 AI 效率工具的单文件 Windows 可执行程序。

**下载 `GoblinTools.exe`（约 16 MB），双击即用** —— 无需安装 Python 或任何依赖，自动打开浏览器。

首次使用：右上角 ⚙️ 设置 → 填入任一 OpenAI 兼容接口（DeepSeek / 通义千问 / Kimi / OpenAI）的 Key → 测试连通性 → 开始。

- ✅ Magic ToDo 任务拆解 · ⏯️ Taskmaster 单步聚焦
- ✍️ Formalizer 语气改写 · ⚖️ Judge 情绪分析
- 🎓 Professor 分级讲解 · 💡 Consultant 决策权衡
- ⏱️ Estimator 时间估算 · 🧠 Compiler 行动项编译
- 👨‍🍳 Chef 食材食谱

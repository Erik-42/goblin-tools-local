Neuf outils d'efficacité assistés par IA, dans un seul exécutable Windows.

**Télécharge `GoblinTools.exe` (environ 16 Mo) et double-clique** — pas besoin d'installer Python ni aucune dépendance. Le navigateur s'ouvre tout seul.

Première utilisation : ⚙️ en haut à droite → Réglages → colle la clé d'une API compatible OpenAI (DeepSeek / Qwen / Kimi / OpenAI) → Tester la connexion → c'est parti.

- ✅ Magic ToDo, découpage de tâches · ⏯️ Taskmaster, une étape à la fois
- ✍️ Formalizer, réécriture de ton · ⚖️ Judge, analyse des émotions
- 🎓 Professor, explication par niveau · 💡 Consultant, arbitrage
- ⏱️ Estimator, estimation du temps · 🧠 Compiler, actions à partir d'un brainstorm
- 👨‍🍳 Chef, recettes avec les ingrédients sous la main

🔒 Les données restent sur la machine. En dehors de l'API de modèle que tu configures, aucune communication avec un tiers.

Le bouton lune / soleil dans la barre passe en mode sombre. Le choix est mémorisé dans le navigateur.
